# Roadmap

**MVP progress: ~48%**

| Phase | Scope | Status |
| ----- | ----- | ------ |
| 1 Foundation | repo, architecture, auth, DB, player, pet, races, stats | ✅ Done |
| 2 Core game | levels, 3 points/level, equipment, random bonuses, upgrade, skills, evolution, sets | ✅ Done |
| 3 Combat | deterministic engine, auto battle, animated replay, result, log, verification | ✅ Done |
| 4 Progression | zones, passive income, rewards, discovery missions | ✅ Done · daily missions + achievements ⏳ |
| 5 Online | async PvP + matchmaking + rating + anti-farming ✅ · profiles, friends, block/report, private messages, chat ⏳ | 🟡 ~35% |
| 6 Economy | marketplace, live trade, transaction history UI | ⏳ Not started |
| 7 Polish | balance pass, sounds, onboarding polish, performance, PWA offline shell | 🟡 ~10% |

## Next milestones

1. **Daily missions + achievements** (First Strike, First Victory, Merchant, Lucky, Collector,
   Evolution, Revenge, Arena King).
2. **Social:** player profiles (Challenge / Trade / Message / Add Friend / Block / Report), friends,
   private messages, general/announcement/system chat (WebSocket).
3. **Marketplace** with escrow, fees, search/filter, price history.
4. **Live trade** (atomic two-sided confirmation).
5. **Balance pass** with the simulator; sounds; art polish.

## Later (not MVP)

Multiple pets per account (schema ready), physical figure codes (stat pipeline ready), cosmetics,
battle pass, guilds (explicitly excluded from MVP).
